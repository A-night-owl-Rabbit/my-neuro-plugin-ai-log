# 思痕之册

> *每一天的对话都值得铭记，每一段记忆都不该被遗忘。*

[my-neuro](https://github.com/A-night-owl-Rabbit/my-neuro) 的 AI 日志插件。当夜幕降临、用户道一声晚安，AI 便会将这一天的对话凝结成一篇带有个人风格的观察日志，写入记忆深处。日复一日，月复一月，这些散落的思绪碎片汇聚成册，成为 AI 跨越重启、穿越时间的长期记忆。

## 前置依赖

> **必须配套安装 [核心记忆注入插件](https://github.com/A-night-owl-Rabbit/my-neuro-plugin-core-memory-injector)**

思痕之册负责将日志写入核心记忆文件，而核心记忆注入插件负责在每次对话时将记忆注入 AI 的意识。两者配合，方能实现：

- **长期记忆**：AI 能回忆起过去每一天发生的事
- **人格连贯**：月度回忆录帮助 AI 建立持续的关系认知
- **记忆永存**：即使上下文被压缩或重置，核心记忆中的日志始终存在

若不安装核心记忆注入插件，日志仍会正常生成并保存为文件，但 AI 在后续对话中将无法自动回忆。

## 快速开始

1. 先安装 [核心记忆注入插件](https://github.com/A-night-owl-Rabbit/my-neuro-plugin-core-memory-injector)
2. 将此插件文件夹放入 `plugins/built-in/ai-log/` 或 `plugins/community/ai-log/`
3. 在 `plugins/enabled_plugins.json` 的 `plugins` 数组中添加 `"built-in/ai-log"`（或 `"community/ai-log"`）
4. 在 `plugin_config.json` 中填写必要配置
5. 重启程序即可

## 配置说明

| 配置项 | 说明 |
|--------|------|
| API 地址 | 用于生成日志的 LLM API 地址（留空则使用主 LLM） |
| API Key | LLM API 密钥（留空则使用主 LLM 的密钥） |
| 模型名称 | 用于生成日志的模型（留空则使用主 LLM 的模型） |
| 日志保存目录 | **必填**，AI 日志文件保存的绝对路径 |
| 日志文件名模板 | 支持 `{date}` 占位符，如 `{date}AI日志.txt` |
| 月度总结文件名模板 | 支持 `{month}` 占位符，如 `{month}-月度总结.txt` |
| 核心记忆文件 | 核心用户记忆文件路径（相对于程序根目录） |
| 对话历史文件 | 对话历史（记忆库）文件路径（相对于程序根目录） |
| 记忆库备份目录 | 写完日志后将记忆库备份到此目录并清空原文件（留空则不备份） |
| 每日日志提示词 | 生成每日日志时使用的系统提示词，按你的 AI 角色自行填写 |
| 月度总结提示词 | 生成月度总结时使用的系统提示词，按你的 AI 角色自行填写 |
| 日志触发时间 | 只有在每天几点之后才允许生成每日日志（默认 21 点） |
| API 最大重试次数 | 调用 API 失败后的最大重试次数（默认 3） |
| 夜间起始时间 | 凌晨几点前算作前一天（默认 7） |

## 功能一览

| 工具 | 说明 |
|------|------|
| `write_ai_diary` | 凝结今日思绪 —— 生成每日观察日志；用户明确要求写日志时传 `force=true` 可跳过时间限制 |
| `read_recent_diary` | 翻阅近日篇章 —— 查看最近几天的日志 |
| `write_monthly_summary` | 编织月度回忆录 —— 汇总上月所有日志 | 编织月度回忆录 —— 汇总上月所有日志 |

## 工作原理

```
        用户说晚安
            │
            ▼
    读取当日对话历史（记忆库）
            │
            ▼
    调用 LLM 凝结为日志
            │
    ┌───────┼───────┐
    ▼       ▼       ▼
 保存日志  写入核心记忆  备份并清空记忆库
 (日志目录) (核心用户记忆.txt) (记忆库备份目录)
            │
            ▼
      核心记忆注入插件
      将记忆融入每次对话
            │
            ▼
    AI 在未来的对话中
    能够回忆起这些时刻
```

## 核心记忆裁剪

每次写入日志后，核心记忆中的**每日日志**只保留最近 1 天、**月度总结**只保留最近 1 个月，避免记忆文件无限膨胀。

## 记忆库轮转

每次生成日志后，插件会自动：

1. 将当天的记忆库备份为 `记忆库-{日期}.txt`
2. 清空原记忆库，为新一天的对话腾出空间

每天的对话历史都作为独立文件保存，既不会无限膨胀，也不会丢失任何一天的记录。

> 如果不需要此功能，将 `history_backup_folder` 留空即可。

## 注意事项

- 日志保存目录（`diary_folder`）为必填项，请确保路径存在或程序有权限创建
- 如果不填 API 配置，插件会尝试使用主 LLM 的配置
- 提示词（`daily_prompt` / `monthly_prompt`）决定了日志的风格和角色，请根据你的 AI 角色自行定制
