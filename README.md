# AI 日志插件

[my-neuro](https://github.com/A-night-owl-Rabbit/my-neuro) 的 AI 日志插件，让 AI 助手在用户说晚安时自动生成每日观察日志，并支持查看历史和生成月度总结。

## 快速开始

1. 将此插件文件夹放入 `plugins/built-in/ai-log/` 或 `plugins/community/ai-log/`
2. 在 `plugins/enabled_plugins.json` 的 `plugins` 数组中添加 `"built-in/ai-log"`（或 `"community/ai-log"`）
3. 在 `plugin_config.json` 中填写必要配置
4. 重启程序即可

## 配置说明

| 配置项 | 说明 |
|--------|------|
| API 地址 | 用于生成日志的 LLM API 地址（留空则使用主 LLM） |
| API Key | LLM API 密钥（留空则使用主 LLM 的密钥） |
| 模型名称 | 用于生成日志的模型（留空则使用主 LLM 的模型） |
| 日志保存目录 | **必填**，AI 日志文件保存的绝对路径 |
| 日志文件名模板 | 支持 `{date}` 占位符，如 `{date}AI日志.txt` |
| 月度总结文件名模板 | 支持 `{month}` 占位符，如 `{month}-月度总结.txt` |
| 核心记忆文件 | 核心用户记忆文件路径（相对于程序根目录） |
| 对话历史文件 | 对话历史（记忆库）文件路径（相对于程序根目录） |
| 每日日志提示词 | 生成每日日志时使用的系统提示词，按你的 AI 角色自行填写 |
| 月度总结提示词 | 生成月度总结时使用的系统提示词，按你的 AI 角色自行填写 |
| 日志触发时间 | 只有在每天几点之后才允许生成每日日志（默认 21 点） |
| API 最大重试次数 | 调用 API 失败后的最大重试次数（默认 3） |
| 夜间起始时间 | 凌晨几点前算作前一天（默认 7） |

## 工具列表

插件提供 3 个 Function Call 工具：

| 工具 | 说明 |
|------|------|
| `write_ai_diary` | 生成今天的 AI 日志（需在配置的触发时间之后） |
| `read_recent_diary` | 查看最近几天的 AI 日志 |
| `write_monthly_summary` | 生成上个月的月度总结 |

## 工作原理

- **每日日志**：当用户说"晚安"等话且在触发时间窗口内（默认晚 9 点 ~ 次日凌晨 7 点），AI 会读取当天对话历史，调用 LLM 生成一份日志并保存到指定目录，同时写入核心记忆
- **查看日志**：读取日志保存目录中最近 N 天的日志文件
- **月度总结**：读取上个月所有日志文件，调用 LLM 生成月度总结并保存

## 注意事项

- 日志保存目录（`diary_folder`）为必填项，请确保路径存在或程序有权限创建
- 如果不填 API 配置，插件会尝试使用主 LLM 的配置
- 提示词（`daily_prompt` / `monthly_prompt`）决定了日志的风格和角色，请根据你的 AI 角色自行定制
